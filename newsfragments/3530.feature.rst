Add a reusable :class:`trio.Barrier` synchronization primitive for a fixed number of tasks. Tasks block in :meth:`~trio.Barrier.wait` until all participants arrive, the last arriver is selected as the unique coordinator for the generation, and cancellation or :meth:`~trio.Barrier.abort` breaks the current generation and wakes the other participants. :meth:`~trio.Barrier.reset` starts an isolated new generation, and :meth:`~trio.Barrier.statistics` reports the waiting count and generation number separately.
